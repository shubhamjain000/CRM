# Introduction

Foundation is a platform built incrementally across 20 phases. Each phase is a
self-contained, verified delivery that the next phase builds on top of.

## What lives here

- **Frontend** — Next.js 16 + TypeScript + shadcn/ui
- **Backend** — Django + DRF + Celery + Channels
- **Mobile** — React Native (Expo)
- **Infra** — Terraform modules on AWS
- **Docs** — this Mintlify portal

## Current state

We are on **Phase 1: Foundation & DevOps**. The structure, local dev stack,
CI/CD pipeline, and health checks are in place. See the
[Quickstart](./quickstart) to get running.
